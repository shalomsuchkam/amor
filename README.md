# Sharkong.kz

Статичный сайт без бэкенда. Три языковые версии с отдельными адресами: `/` (RU), `/kk/`, `/en/`.

## Загрузка на хостинг
Распакуйте архив в корень сайта как есть. Папку `.well-known` не удаляйте (нужна для SSL).

## Как менять сайт
- Текст и разметка: `src/template.html` (русский текст прямо в нём), переводы kk/en: `i18n.js`
- После правок: `python3 tools/build.py`, затем `python3 tools/audit.py` (SEO-проверка, должно быть 0 ошибок)
- Сборка создаёт `index.html`, `kk/index.html`, `en/index.html`, `sitemap.xml`, `robots.txt`, `404.html`, `manifest.webmanifest`, `llms.txt`
- Заявки и калькулятор уходят в WhatsApp (+7 777 594 83 84), CRM не нужна

## Фото
Новые фото кладутся в `assets/` (webp, 1323 px и версия 800 px). Имена, которые использует шаблон: `living`, `bedroom`, `kitchen`, `bathroom`, `hall`, а также `d-*.webp` для карточек «Детали».
