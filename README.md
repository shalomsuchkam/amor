# Sharkong.kz

Статичный сайт (HTML, CSS, JS без сборки). Загрузите содержимое папки на хостинг как есть.

- `index.html`, `style.css`, `script.js`, `i18n.js` - сайт, языки RU / KZ / EN
- `assets/` - оптимизированные изображения (webp)
- `.well-known/` - нужен для продления SSL
- Форма и калькулятор не требуют бэкенда: заявка открывается в WhatsApp (+7 777 594 83 84)

Локальный запуск: `python3 -m http.server 8000`
